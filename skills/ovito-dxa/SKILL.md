# OVITO DXA 优化指导

默认用中文交流。先保持科学含义和结果可核查，再减少重复计算、提高吞吐。所谓最优配置是同一批样本、同一分析定义下的实测选择，不是固定的进程数或保证加速倍数。

## 先发现，再确认

1. 根据用户提供的范围只读检查文件、已有代码和可用解释器。先读 [输入判断](references/input-decisions.md)，使用 `scripts/inspect_inputs.py`；不要自动安装或升级环境。
2. 先区分用户有**单组完整数据、多组独立数据，还是已有分析脚本**。一组数据可能是单个构型，也可能包含一条多文件、多帧轨迹；不要把“单组”当作“单帧”。目录名、取向、温度、速率等仅是线索。多文件是否同组、排列顺序和对应工况不明确时询问使用者。
3. 从文件或已有代码能查明的信息不重复提问。无法可靠确定的参考晶格、原子选择、单位、PBC、帧范围、密度体积和输出档次必须确认；不继承任何示例中的 BCC、Fe/H、类型 ID、固定层、阈值或工况组合。
4. 仅当前阶段需要的信息确认后才进入下一阶段。用户逐步操作时，等待本步结果后再给下一步；用户已明确授权的范围不反复确认。缺少必要信息时不给带占位符或猜测参数的运行代码。

## 确认任务并验证

- 将确认后的输入映射写入 [任务清单](references/task-manifest.md)；源文件必须显式列出。`confirmed: true` 只能反映用户已确认的科学设置与分组，不能由模型代替确认。
- 统计档输出逐帧线长、分类长度、盒体积及定义明确时的密度；几何档另存逐线数据和 CA 网络。每次确认实际需要哪档，不默认保存庞大的全量几何。
- 审查已有脚本时先记录指标、参数及输出约定；将纯性能变化与科学算法变化分开。若已有代码的距离、体积或选区定义存疑，指出并询问，不在“提速”过程中静默修正。
- 阅读 [性能方法](references/performance.md)，完成只读输入预检和必要的科学确认后，默认直接用 `scripts/run_dxa.py` 的 run 模式处理所选帧；默认 2 个 worker、每个 worker 1 个 OVITO 线程，实际受任务数和 CPU 限制。独立单构型或仅 1 个 CPU 时用 1 个 worker，是任务或资源限制，不是额外串行基线。预检只读取元数据，不执行 DXA。
- Notebook 主流程为 `%%writefile DXA_Multiprocessing.py` 保存薄入口，再用 `%run DXA_Multiprocessing.py` 执行；入口从可导入的 `run_dxa.py` 调用 `main`，Windows 的进程池 worker 必须定义在可导入模块内，不放在 Notebook 临时 `__main__`。薄入口显式设置 `__spec__ = None`，避免 IPython 重复 `%run` 时缺少 spawn 所需的脚本元数据；`%run` 不是并行机制。
- 仅在用户要求性能对比时，从每组选定范围的首、中、末选取去重候选帧，再按默认全局最多 6 帧运行 benchmark；未抽到的工况不属于本次验证；不要为对比而对所有帧先做串行计算。展示真实耗时、峰值内存、结果一致性和报告；推荐仅依据本次样本，不将辅助脚本基线称为旧代码性能。对照失败或未实测不得声称提速。
- 按用户授权进行正式运行；有失败时保留失败帧和原因，不能用零线长或“全部完成”掩盖失败。恢复前检查来源、帧映射、参数和版本是否兼容。

## 科学边界

- 对 DXA 选择参考晶格、原子集合和搜索参数必须有依据；替位合金不能按化学类型随意删除原子。一般晶界或多相界面超出可靠解释范围时说明边界。
- 长度和体积保留输入单位。密度的分子与分母必须对应同一统计区域；不能扣除固定层体积但保留整个体系的位错线长。复杂有效体积、空间选区和线段裁剪走专用方法，第一版内置运行器仅支持已确认的整盒密度。
- 保留各帧盒形和周期边界；不把 LAMMPS data 读者的默认边界当成真实模拟条件。帧索引、模拟步及物理时间分别记录，缺失时间不虚构。
- 零位错、无晶态原子与计算错误分开。结构识别比例是诊断信息，不是平衡、收敛或物理有效性的证明。
- 位错线的编号、分段及方向可随帧改变，不能直接当作持续追踪。CA 是位错网络输出，不替代原始原子轨迹；基于两帧的比较不是完整轨迹重建。

## 按需扩展与交付

只有用户请求氢或其他溶质相关分析时，读取 [溶质分析](references/solute-analysis.md)，先确认选择、距离、周期边界和统计定义，再生成并验证专用代码。第一版没有内置通用距离或位错追踪算法。

交付明确区分已完成、已实测和未验证内容。提供真实可运行路径、带逐行中文注释的代码、任务清单和指标解释；仅在实际执行后提供对应运行报告。保留原始输入和用户脚本，输出到独立目录。公开分享仅使用合成数据或已获许可的样本，不包含私有研究数据。
