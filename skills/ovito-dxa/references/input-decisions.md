# 输入检查与待确认事项

`inspect_inputs.py` 使用当前解释器中的 OVITO **只读**检查各输入文件，不创建或运行 DXA 修饰器，也不自动生成、确认或修改任务清单。请先正常激活已有 OVITO 环境；工具不会安装或升级包。

命令行的 `--paths` 接收一个或多个已确认的真实文件或目录路径。目录默认仅检查直接子文件。带 `--recursive` 才递归。`--all-frames` 读取每个已发现帧，并对受覆盖的文本 dump 流式扫描完整 `ITEM: TIMESTEP` 头，与 OVITO 实际发现的帧数比较；默认仅检查首、中、末帧，不执行该完整头扫描。默认不会完整计算哈希，`--hash` 才读取所有文件字节计算 SHA-256。`--script` 只解析所指定 Python 文件的 AST，不导入或执行；其候选问题必须人工复核。可以单独指定 `--script`，此时不需要指定 `--paths`，也不导入 OVITO；两项不能同时省略。`--output 路径` 才另存 UTF-8 JSON，目标必须尚不存在；报告仍会打印到 stdout。`--atom-style` 明确指定 data 的 atom style，`--atom-substyles` 接收 hybrid 的一个或多个子类型。

## 输出字段与边界

报告 `schema_version` 为 1，`environment` 给出解释器、OVITO、CPU 和可用内存，`inputs` 逐文件给出 OVITO 实际读取器、格式、状态、首中末或全部已发现帧的读取结果、盒矩阵、读者报告的 PBC、粒子数、数字类型、帧内 ID 唯一性以及原始 `Timestep`/`Time`。`questions` 列待用户确认的事项，`errors` 与 `warnings` 区别读取失败和结论限制；退出状态 0 表示本次检查没有发现读取错误，1 表示检查失败，2 表示另存报告失败。

读取器按内容由 OVITO 识别，不单凭文件扩展名；仅接受运行器支持的 LAMMPS data 和 dump。gzip/zstd 是否能读取取决于当前 OVITO 读者和本机环境，成功或失败均以实际结果为准。空文件、读取失败、空帧、非有限粒子坐标、二维盒和文件检查期间变化会报告错误；二维盒不属于此工具支持的常规三维 DXA 路径。重复 ID 单独报告警告，它限制跨帧原子对应，但不因这一检查单独拒绝单帧几何 DXA；若读者本身拒绝，仍报告实际读取错误。检查仅比对读取前后文件元数据，不能证明源文件没有隐蔽变化；完整 SHA-256 是可选操作。文本 dump 的完整头扫描在 `text_dump_scan` 中单独报告头数、覆盖状态、错误及耗时；普通、gzip 和环境已安装 `zstandard` 的 zstd 文本输入可扫描。二进制、YAML、没有 zstandard 支持的 zstd、异常长行或无法识别的内容会报告未覆盖，不能声称完成文本头校验。比较头数可以发现源中有更多完整头但 OVITO 漏掉帧的情况，但不能证明每条原子记录都正确，也不能保证发现缺少完整末尾头部的截断文件。

检查器绝不把目录或多个文件自动视为同一轨迹；必须确认文件归属、工况、时间顺序和文件格式。含 `%` 的文件名会停止检查并提示可能的 LAMMPS 并行分片，其他实际分片文件不一定包含字面 `%`，需人工确认，首版运行器不支持未合并的分片。单一 data 是结构快照，不因此假定时间；其 PBC 输出仅为读者报告，不能作为模拟实际边界，应按用户提供的原始模拟设置确认。dump 的 `Timestep` 是模拟步，`Time` 仅在输入提供时可读，帧索引并非模拟步或物理时间。应按输出需要确认长度单位、类型含义、宿主选择、晶格和预期分析；不要默认某个元素应删除或假定轨迹连续。仅当需要物理时间轴时，才需要确认时间单位，并在输入不提供时间时补充步长和时间原点；单纯几何 DXA 不要求这些时间信息。

对于 data，报告 `atom_style` 保留 OVITO 读取器暴露的原始值、用户指定值、`Atoms` 行注释以及来源（`user`、`header`、`reader_guess` 或 `unknown`）；`unknown` 读取器值并不等于已知采用某个样式。对普通、gzip 与 zstd（需要当前环境已有 `zstandard`）最多读取 4 MiB 解压后头部，无法找到头行或读取解压头时会报告未知而不假定没有提示。没有提示又未指定样式时，OVITO 即使成功推测也必须要求确认，不能把推测写作确认事实。

`--script` 对循环中的可疑修饰器 `append`、循环或函数中的 `import_file` 给出行号；静态检查不推断运行次数，也无法发现所有间接调用和别名。函数内部的 `import_file` 可能只是每进程初始化，候选提示不等于错误。

## 检查器与运行器的区别

检查通过并不表示科学设置已确认，也不等于运行器预检通过。运行器还必须核对已确认的 case 分组与帧范围、支持的 DXA 参数、PBC 和单位、输入版本/摘要、输出目录、资源约束、检查点兼容性，并在需要时验证实际计算结果；不得把此检查报告自动变成 `confirmed: true`。
