# 溶质与位错相关分析：按需生成

仅在用户明确需要氢或其他溶质与位错的关系时读取。本页提供决策规则；第一版辅助脚本没有内置通用距离、富集、通量或位错追踪模块。不能在只要求 DXA 时自动追加这些分析。

## 在编码前明确统计问题

从输入和已有分析能确认的信息不重复询问；其余按当前问题补问：

- 宿主晶体及溶质的类型映射；间隙还是替位，是否需要仅对某个子晶格做 DXA。类型编号不等于固定的元素名称，不默认 H=2 或 Fe=1。
- 分析哪些溶质：全部、初始选择固定的 ID 集合，还是每帧按空间条件重新选择。若固定层有移动或原子跨区，这几种定义的结果不同。
- 目标是逐原子距离、阈值内数量/比例、局部浓度、相对体相的富集，还是跨帧变化。只得到邻近比例不能直接称作富集倍数；空间聚集不能直接称作通量。
- 距离指向离散线点、折线线段、平滑曲线，还是位错核心区域；阈值的数值和单位由使用者确认，不默认 5 Å。
- 周期方向、逐帧晶胞矩阵及盒原点，是否发生剪切或形变；是否保留相同原子 ID 以进行跨帧比较。

DXA 默认忽略化学类型；`only_selected` 会将未选原子视作不存在。替位合金按元素删除原子可能改变宿主结构，应基于材料和目标确认选择，而不是套用含间隙氢的案例。[官方说明](https://docs.ovito.org/reference/pipelines/modifiers/dislocation_analysis.html)

## 距离计算必须符合定义

`cKDTree` 可有效查询到离散顶点的距离，但不是严格点到线段距离。线点疏密、平滑与粗化会影响这种近似；不能只替换数据结构就宣称精确度没有变化。

精确折线距离需要保留每条线的分段关系，计算点到每条有限线段的投影与端点距离，不能将所有线点拼成一条新折线。空间索引可以做候选筛选，但必须验证不会漏掉真正最近线段；以端点最近邻代替线段候选不能保证精确。

周期情况必须使用实际每帧晶胞和 PBC。正交盒的周期 KDTree 选项不能直接推广到三斜盒或混合周期边界。三斜盒简单逐分量取整不一定得到欧氏最近镜像；需要验证的周期几何算法和足够候选镜像。对跨周期边界的线先明确其连续表示，不要把顶点分别 wrap 后直接连接，从而制造穿盒假线段。

线方向可能翻转，Burgers 矢量的表示与参考晶格相关。逐帧 line ID 不是追踪 ID；如果需要位错迁移、速度或一条线的演化，必须另设计匹配与不确定性处理，不能从独立帧编号或两个端点直接推断完整轨迹。

## 结果及异常约定

- 无被选溶质时，数量可以是 0；比例和平均距离需要明确为未定义，而不是 0。
- 成功 DXA 且无位错时，不伪造零距离；按确认语义给出空几何及未定义或无穷距离。DXA 失败必须保留为失败。
- 跨帧原子顺序不稳定时按唯一 ID 对齐；ID 缺失或重复时不能假装完成了逐原子追踪。
- 浓度和富集需要相应体积、参考浓度及重叠管域处理；不能用线长简单乘圆柱截面积就忽略结点重叠、周期重叠与表面截断。
- 单位、原子集合、阈值、距离对象及周期算法写入输出元数据。与旧方法不同的定义应另存结果，不覆盖原方法。

## 最小验证集

先在解析或小型人工几何上验证：点在线段内部投影、端点外、折线拐角、零长度段、多个不相连线段、无位错、无溶质、正交跨界、混合周期及倾斜盒。周期测试与明确枚举足够镜像的参考计算比较；数据规模小不代表几何情形可以省略。

确认小例正确后，再对一组真实样本比较旧方法与新方法。将算法定义改变导致的差异和纯性能变化分别解释；只有完成实际对照才报告提速。
